# Phase 2.1 context

Accepted roadmap: bounded relay query and compatibility, with Feed Lab on Android and iOS. This context is reconstructed from the approved roadmap and canonical shared capability plan; no new product scope is introduced.

- Use the selected NAP-RELAY draft at `0be8abce18beb46ca37bd4ddd042f58d30b4eedc`, verified as PR 2 head on 30 September 2026.
- Query is read-only. Existing individually approved publication remains unchanged. Subscriptions, outbox, resource sidecars and encrypted publication are later or unsupported work.
- Native process owns destinations, identity epoch, registration and network access. Guest requests cannot select destinations or identities.
- Reuse the app-only native WSS query transport, with a distinct validated guest-query service and broker checks. Do not reuse manifest-only verification as event validation.
- Required domains remain admission hints; implementing query does not promise every relay operation or make cvm/webrtc napplets executable.
- Keep foundation/device gaps open while implementing this independent slice.
- Run work inline under the installed GSD fallback. No typed-agent plan-checker or verifier execution is claimed.
