# Schemes, bulk, cache and settings

NAP-RESOURCE PR13 is pinned to `8c0645d32ceb159bc3e8bcec1107a92862b7e86a`; the [selected profile](../../../docs/resource-access.md) identifies exact wire, scheme, MIME, size, cache and lifecycle behavior. Genuine SDK 0.27.2 uses Kehto's injected facade and host-only overrides. Inline GSD fallback was used; typed agent guarantees are not claimed.

Both native hosts retrieve the SHA-256-verified Blossom PNG through the default Primal redirect, a strictly verified signed Nostr event as one-hop JSON, and host-mediated data JSON. Ordered bulk preserves exact bytes, successful siblings and canonical unsupported-scheme errors. Private DNS destinations are denied. Native SQLite settings survive cold restart; disabling Blossom retains already-loaded memory cache, while close/reopen drops it and denies new Blossom retrieval until defaults are restored.

The default download origins are Primal and Satellite. A verified Primal download does not establish availability of every configured server. Defaults do not choose an upload provider. Controlled tests cover hash mismatch/fallback, scope isolation, LRU/byte/rate/process budgets and uncooperative cancellation. Hashtree and network-free SVG rasterization remain explicit post-Phase-4 gaps.
