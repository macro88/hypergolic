# Public identity UI

Extend existing State Lab/Feed Lab styling and controls. Label each read and list selection; show loading, empty, data and error distinctly. Render all profile/list metadata as text and URL strings, without automatic remote images. Clear/ignore old-user UI responses on identity change. Use semantic native buttons and web labels/status regions. Sensitive-list review uses the trusted shell's existing modal language and names selected identity, publisher/app, public mutes/bookmarks/pins/interests, remembered access and rejection. Settings lists current user's allowed apps with a revoke control and a durable success/error status. Preserve native guest margins and control room at narrow widths; verify screenshots and input on both native hosts.
