# Public profile and durable cache tracer

State Lab now reads the selected user's public profile through the genuine SDK,
Kehto, native capability transport, the process-owned resolver and trusted WSS
query service. Only verified kind0 metadata is projected. `display_name` maps to
`displayName`; literal allowlisted strings do not fetch URLs or grant payment
support. Recent source data lasts five minutes. Older validated cache can survive
a failed bounded refresh; unavailable data without a cache returns an error.
Signed newest-event selection prevents downgrades; equal timestamps use the lowest
lexical event ID. A signed empty object clears earlier metadata, while empty EOSE
cannot delete a known signed event. Reopening revalidates stored signatures.

64 rows/4MiB total and256KiB bundles. Captured identity, request lifetime and
revocable owner checks apply before reads, commit and delivery. The resolver has
bounded concurrency/deadlines and releases cancelled request quota promptly.
