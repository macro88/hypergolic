# Phase-zero setup

1. Review the seed and verify tool provenance and supported runtime versions.
2. Install pinned tools, scaffold the Android app, and record native generation inputs.
3. Run TypeScript, Expo Doctor, React Doctor, aislop, dependency audit and Android export.
4. Attempt native compilation; document signing/device proof separately.
5. Commit and push on the verified application branch; record the validation checkpoint.

The evidence document is the result record. Do not mark native or device checks
complete on the strength of bundle export, planning validation or tool installation.
