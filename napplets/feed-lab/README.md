# Feed Lab

Unsigned embedded fixture for the selected NAP-RELAY query and subscription profiles. Uses genuine SDK 0.27.2. Query notes sends editable NIP-01 filters; Query empty sample uses limit zero. Distinguishes loading, successful results, empty EOSE and errors. Untrusted note content is rendered only as text. Start live feed streams signed matches before and after EOSE; Close live feed closes its SDK handle. The feed retains 32 rows and an editable draft. No direct networking, signing or persistent storage.

Run `pnpm install --frozen-lockfile`, then `pnpm verify`. Browser mocks establish SDK/UI behavior; native and published journeys need separate receipts. Shell Settings exposes the embedded fixture after its generated bytes are reviewed and pinned. The [subscription profile](../../docs/relay-subscriptions.md) records the confirmed lifecycle and both native hosts’ scoped acceptance; full published/physical compatibility remains open.
